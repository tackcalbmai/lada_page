# lada_page

Starter сайта тату-мастера с фокусом на микрореализм.

Стек: Astro + Decap CMS + Cloudflare Pages.

Сейчас заложено:
- основной стиль: микрореализм;
- портфолио: «Работы» и «Cover-up»;
- услуги и цены;
- FAQ;
- блог;
- WhatsApp-заявка;
- админка `/admin`.

До запуска нужно заменить данные мастера, реальные фото, номер WhatsApp, домен и закончить авторизацию CMS.
